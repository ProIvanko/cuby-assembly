## Что делает приложение

Инструмент для отслеживания хода монтажа модульного здания в режиме реального времени.  
Каждый строительный элемент — это 3D-объект на сцене с собственным статусом, чеклистом, оценкой качества и фотографиями.

Ключевые функции:
- интерактивная 3D-сцена с вращением, масштабированием и выбором элементов
- три статуса монтажа: **не установлен / в работе / установлен** — с визуальной раскраской
- оценка качества узла: **принят / доработка / брак**
- чеклист выполненных работ для каждого элемента
- редактирование положения и поворота элемента с живым обновлением в сцене
- вложение фотографий (base64) и текстовых заметок
- счётчик готовности всего объекта

## Ключевые технические решения

**Координатная конвертация AutoCAD → Three.js.**  
AutoCAD использует систему координат с осью Z вверх, Three.js — с осью Y вверх.  
Решение: поворот корневого объекта на −90° по оси X при загрузке каждой STL-модели.

**Масштабирование.**  
AutoCAD экспортирует геометрию в миллиметрах; сцена Three.js работает в метрах.  

**Центрирование геометрии.**  
После загрузки STL вычисляется BoundingBox и геометрия смещается к локальному нулю,  
что позволяет задавать позицию и поворот элемента в понятных координатах.

**Angular Signals для реактивного UI.**  
Весь стейт приложения — в одном сервисе на сигналах. Компоненты не хранят данные;  
изменение статуса в сервисе немедленно перерисовывает только затронутые части экрана.

## Архитектура

```
src/app/
├── models.ts           — интерфейсы AssemblyNode, ChecklistItem, типы NodeStatus / QualityGrade
├── state.service.ts    — единственное хранилище данных (Signals)
└── components/
    ├── viewer.component.ts     — Three.js сцена, загрузка STL, раскраска по статусу
    ├── sidebar.component.ts    — список элементов, фильтры
    ├── node-panel.component.ts — форма редактирования узла (позиция, статус, чеклист)
    └── header.component.ts     — общий прогресс объекта
```

## Контекст проекта

Приложение создано как практическая демонстрация навыков для позиции **JavaScript-разработчика в компании модульного строительства**. 
Автор — инженер-конструктор с опытом проектирования в AutoCAD и Tekla Structures, что позволило интегрировать реальные CAD-данные напрямую.
